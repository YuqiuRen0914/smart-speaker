# 设备协议快照

本组件保留当前音箱依赖的公开协议头、帧编解码和设备 profile，不引入其他产品的实现。已生成代码随源码提供，常规编译不执行协议生成器。

生成输入快照位于 `schema/device-contract-v1.json` 和 `schema/remote-control-v2.json`，原相对路径和摘要见 `schema/sources.json`。头文件中的原始生成器路径仅记录导入时的来源；本独立工程不要求取得或运行原仓库工具。

协议升级须在本组件内提供相应的生成/校验工具并验证线格式兼容；不得通过引入其他产品源码或恢复外部仓库路径完成升级。此次迁移没有改变协议布局。
