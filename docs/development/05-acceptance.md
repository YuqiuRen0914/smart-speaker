# 验收清单与证据要求

状态：首发验收方案 v0.1，2026-11-10。以下是待执行的场景，不代表当前结果。P0 补测量方法，阶段交付记录实际证据。

## 1. 证据分层

每个用例分别记录“未执行／通过／失败／待外部条件”，并注明证据层级：

1. 源码检查：证明路径、配置、依赖与所有权，不证明声音和视觉效果。
2. 主机验证：证明规则、状态、协议和错误路径，不证明 ESP32 性能。
3. 固件构建：记录 SDK、任务 UUID、产物摘要和路径审计，不证明已安装。
4. 设备／外部端运行：注明实际场景、结果和观察范围；主机模拟、Mac 与 Windows 不能相互替代。
5. 联合负载：注明同时开启的能力、持续时长、操作序列和资源变化，不从短时演示推断长期稳定。

已有基线验收引用 `docs/baseline-correction.md`。本计划增加的新能力单独验收，历史结果不能自动升级为新版本通过。设备日志、凭据和私密身份信息留在本地忽略目录，文档只写必要脱敏结论。

## 3. 必测跨模块序列

### 3.1 恢复不能覆盖新意图

1. 开始播放 A 曲，打开助手。
2. 让助手停止音乐，结束对话。
3. 返回原页面后音乐保持停止；不存在延迟到达的旧恢复命令。
4. 再测原本已暂停、对话中换曲、取消、超时和游戏嵌套四类变体。

### 3.2 提醒延后与错过

1. 在对话期间使提醒／番茄钟到点；只显示标记，不让短提示音进入正在进行的对话。
2. 结束或取消对话；待处理记录仍在，按规则弹窗并短响一次。
3. 重启模拟关机错过事件，可信校时前不响；校时后标已错过且不补响。
4. 再次重启／校时不产生同一事件的新提示音；按周规则仍有下一次。

### 3.3 资源事务与生产状态

1. 已有可用歌曲、封面和壁纸时，分别尝试上传损坏文件、取消和写入失败。
2. 原资源仍可使用，临时文件不进入正式索引，网页准确显示失败。
3. 重开网页／页面和重启后核对状态；不能只检查浏览器显示“100%”。

## 4. 性能与稳定性记录

P0 定义采样方式和代表场景；P1／P3 记录可复现的数值预算、硬件条件、资源版本与理由。阈值尚未确定时只报告实测，不能写“满足要求”。不要因为一次超限就单纯提高阈值。

| 维度 | 至少记录 |
| --- | --- |
| 显示 | 局部／完整刷新耗时、失败、像素传输量、动画实际刷新、列表操作时输入响应 |
| 音频 | I²S 错误／短写、最大写间隔、可闻断音、左右输出、焦点切换与取消后的恢复 |

| 网络 | 掉线／重连、服务超时、上传取消、天气后台更新对前台的影响 |
| 稳定性 | 运行时长、操作次数、panic／重启／看门狗告警、资源泄漏和未处理错误 |

建议首轮采用持续播放至少 30 分钟、关键页面往返至少 100 次的重复操作样本，再按风险加长。该时长是初始验证方案，不是长期可靠性的证明；发现问题后保留失败记录并复测相关场景。未执行的时长和次数不得填为完成。

## 音乐唱片页补充验收（2026-11-12）

- 在本地音乐页左滑下一首、右滑上一首，页面不退出且音量不变；歌名、封面、歌词和频谱对应新曲。核对暂停时手动切歌、单首／空曲库、播放模式和歌曲边界，沿用原播放器结果。
- 上下滑动不切歌，点按／左键播放暂停、旋钮音量及右键返回不变；白噪声页和其他功能页不因横滑切歌。助手等待启动及连接／聆听／思考／回答时拒绝页面切歌；返回菜单时残留手势被丢弃。源码／主机测试不替代真机手感和声音验收。

- 在「音乐 → 本地音乐」核对圆形封面、默认黑胶、暖黄环形频谱、顶部歌名及底部单句歌词；歌名固定、长歌名省略，长歌词滚动，不覆盖频谱或越过屏幕。
- 用低频／中频／高频及真实歌曲分别验证响应，静音音频帧应回落；主音量为零时仍反映源歌曲动态。暂停平滑停转，恢复不重播旧频谱；停止、缺卡和资源失败有实际反馈。
- 从网页切歌、替换／删除封面，反复退出／重新进入、发起／取消助手；声音继续遵循原播放意图，旧采样和旧封面不复活。白噪声和首页保持原入口行为。
- 记录本页持续播放与网页上传／网络并发下的实际帧时、最大音频写间隔、可闻断音、DMA／内部连续内存、PSRAM 和故障日志。主机通过／构建通过与这些实机结果分别记录。

- 上传含 ID3v2.3／2.4 APIC 与带时间戳 USLT 的 MP3，核对曲库 `has_cover`／`has_lyrics`、屏幕封面和逐句歌词。已存在同名歌曲再次选择时只补缺失侧文件，保留手动导入的内容；中途失败可重试，不把部分成功显示成全部成功。
- 注入播放器文件读取错误：必须显示存储卡读取失败并停止，不按正常 EOF 自动切歌；正常 EOF 的顺序／随机／单曲循环行为保持。SD 挂载失败应释放 DMA 预留，卸载失败仍保留，成功卸载后释放。
- 用原始 Let Go 持续播放整首，核对约 1.9 秒处不再提前停止，并记录音乐页帧时与音频故障计数；主机测试和编译结果不能代替这项实机验收。

- 音乐页直接绘图：检查标题、歌词和音量不被唱片覆盖；进入／退出、助手覆盖和全屏重绘后恢复。帧率使用 `music_presented_frames` 差值；暂停稳定后应停止提交唱片，恢复继续。对声音连续性的用户确认与设备计数分别记录。
- 网页封面：保持曲库页打开，重复轮询不会重建封面节点／改变 URL；显式替换封面和手动刷新可以更新图像。确认浏览器已重新加载新版页面后，再评估联合负载。

## 环境声补充验收 A-AMBIENT（2026-11-12）

- 四场景：首次预览不发声，确认播放后可左右直接切换；已选择用户指定沙岸录音。
- 纯壁纸与操作浮层；定时选项常驻，右键关闭再返回；旋钮只调音量。
- 返回菜单/时钟继续，切音乐取消环境声定时；语音临时暂停及恢复不丢失原状态。
- 定时持续/30/60/90，暂停/切场景/语音不延后；末 5 秒渐弱，到点包括语音期间也撤销恢复。
- 网页装四音源与单独装一个；不合法 WAV、超限、暂停/播放中安装、取消、掉线、SD 满及断卡。
- 自选壁纸逐场景保存/重启恢复/默认恢复；被引用图拒删，保存失败保留旧图，损坏用默认图并提示。
- 自动证据：实际生产手势路由、计时逻辑、源读取/循环/衰减、上传中断/回滚、资源持久化及 LVGL 预览。
- 真机仍需：接缝听感、鸟鸣/杯盘突发音、音量一致性、触摸位置、语音重叠、长时连续播放与 SD 联合负载。
