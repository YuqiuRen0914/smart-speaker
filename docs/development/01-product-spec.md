# 产品规格：个人桌面智慧终端

状态：已确认需求的整理，v0.1，2026-11-10。技术选型中尚未确定的事项见实施计划，不默认为已确认需求。

## 1. 定位与首发目标

设备是可独立运行的个人桌面智慧终端，以音乐、桌面宠物助手、时间和桌面信息为核心。电脑不在线时，本地音乐、计时和设备交互仍应可用；云端对话、天气等联网功能按各自网络状态工作。

本地应用入口在 240×240 屏幕上一屏一个应用，显示大图标、名称和页码指示；不显示功能小字介绍及底部操作提示。首页空白处左滑进入；左右滑动或转旋钮切页，点按／左键进入，右键返回。二层选择保留 AmoledOS 纵向条目。

## 2. 首发功能范围

| ID | 一级模块 | 首发能力 | 边界 |
| --- | --- | --- | --- |
| F-MUSIC | 音乐 | SD 本地曲库播放、封面、歌词、白噪声 | 网页上传音乐及关联文件；不引入在线音乐平台 |
| F-AI | AI 助手 | 当前版大肥鱼桌面宠物、日常语音对话、控制音箱功能 | 设备直连小星使用的 LunarLink 平台；全局按键／唤醒词发起单轮对话 |
| F-TIME | 时间管理 | 时钟、番茄钟、具体日期时间提醒、按周重复提醒 | 同一份计时／提醒数据供设备、网页和 AI 使用 |
| F-INFO | 信息看板 | 天气、日期、月历、本地提醒标记 | 不接外部日历账号；天气来源与配置细节待实现阶段确定 |
| F-GAME | 游戏娱乐 | 电子木鱼、2048 | 二层菜单选择；不做通用游戏运行平台 |
| F-PC | 设备协同 | 电脑 CPU、GPU、温度、风扇等运行指标 | macOS、Windows；仅保存一台配对电脑；指标依硬件和权限可用 |

另有独立设置入口，用于网络、显示／桌面、声音、AI、电脑配对等必要设置，不作为第七个业务模块。具体设置页组织在 P1 形成页面清单。

### 2.1 桌面

- 静态壁纸为唯一首页，常显日期、大号时钟、真实天气图标及温湿度读数；不重复显示天气名称、刷新状态和数据年龄。右下角显示鲸鱼娘，不显示手势提示。空白处左滑进入应用；时间管理和信息看板应用提供完整详情。
- 壁纸支持网页上传、预览、选择；首发不支持动态壁纸。无图时黑底；已有设置中保存的壁纸继续恢复，文件失效时提示重新选择。
- 天气显示真实来源快照及数据年龄，区分未配置、更新、离线缓存、过期及失败；未校时显示缺失时间，不在产品路径填演示数据。
- 开机动画基于用户认可的开源参考方向：黑底、黄色细线展开，首页原有白色小时与黄色分钟显露；显示真实网络状态与版本，无假百分比／未校时时间。联网／校时不阻塞本地功能；无网络时有限等待后退出，需要配网时交回已有入口。只在本次开机播放，后续重连不覆盖正在使用的页面。
- 开场与信息首页采用同一组时钟控件：居中显露后平移到首页原位，再依次带出秒数、日期、天气、温湿度和背景。参考 X-TRACK 的克制风格与 LVGL Music Demo 的连续编排；此前活动条／整体渐隐方案被用户否定。转场中显式导航仍可立即打断；配网页保留对应退场路径。
- 首页鲸鱼娘与全局助手入口使用同一助手会话状态，不创建两套助手；角色上方不显示空闲状态下的呼叫提示。
- 大肥鱼动作由状态／情绪动画片段和语音强度反馈组合，不要求音素级口型同步。
- 新版形象来源为 `PC2005-cloud/dsh-pet`，其完整原始动画已归档。当前实现支持 114 段点播、随机小动作、睡眠、点击、拖拽甩抛、弹弓、IMU 倾斜／摇动和小智会话动画。从鲸鱼娘身上开始的触摸服务宠物，音乐通过现有旋钮、实体键和音乐页面操作。从壁纸空白处左滑进入应用。设备需安装 SD 动画包；真机及全量动作见 [角色方案](06-pet-character.md)。

### 2.2 网页管理端

- 在局域网中提供音乐上传到 SD、本地曲库管理、歌词与封面关联。
- 提供 EQ 调音和预设效果、AI 配置、静态壁纸管理。
- 时间管理能力与设备及 AI 共用数据；网页提供相应的配置和状态入口。
- 网页显示真实设备状态和操作结果；浏览器本身不持有另一套有效业务状态。
- 页面具备上传进度、失败信息和基本预览；具体页面样式不强制复刻设备界面。

### 2.3 电脑采集端

- macOS 菜单栏／Windows 托盘轻量运行，提供连接、状态、退出等必要操作。
- 仅局域网通信，不以云端账号或远程公网服务作为电脑监控的前提。
- 只保存一台配对电脑；更换电脑替换原有配对，不维护多机列表。
- 可以使用需要额外权限的传感器组件；采不到的指标明确显示“不支持”“无权限”“离线”等原因，不能伪造为 0。
- 首发只查看运行指标，不增加电脑远程控制、文件同步或完整 PC 管理面板。

## 3. 导航与输入

一级列表包含六个模块，每个模块可进入二层选择页，例如“游戏娱乐 → 电子木鱼／2048”。功能详情、编辑表单和确认弹窗不等于无限嵌套应用文件夹；首发不建设任意深度菜单系统。

| 页面 | 旋钮 | 左键短按 | 右键短按 | 触摸 |
| --- | --- | --- | --- | --- |
| 首页 | 音量 | 上一首 | 下一首 | 壁纸空白处左滑进入一级应用 |
| 一级应用 | 选择应用 | 进入 | 回首页 | 横向滑动选择，点按进入 |
| 二级菜单／设置 | 选择条目 | 进入／确认 | 返回上一层 | 纵向选择，点按确认，横向不导航 |
| 功能页 | 页面定义；音乐为音量 | 主操作 | 返回上一层 | 功能自身处理 |

- 全局左键长按 800 ms 发起助手，右键长按 800 ms 取消对话并直接回首页。到阈值即触发一次，松手不触发短按；不显示长按文字、进度条或预备动画。双键同按不产生动作。
- 一级应用在首尾停止，不循环；本次开机记住选择，退出到首页／从二级返回都恢复，重启选第一项。
- 音乐左键播放／暂停；番茄钟左键开始／暂停／继续；木鱼左键敲击。2048 仅四向触摸移动，左键和旋钮不动棋盘，右键保留返回。
- 页面切换或助手获得输入权后，旧按压、触摸和旋钮积压不得落入新页面。触摸长按不再发起对话，宠物按住后仍可拖拽。

## 4. 语音对话规则

1. 全页面支持左键长按和本地唤醒词“你好小智”（包括音乐、游戏）；“大肥鱼”自定义模型暂缓。保持设备停用／麦克风静音策略。松键不结束录音，自动判断说话结束。
2. 默认单轮：输入结束 → 云端处理 → 播放回答 → 结束本轮采集／上传 → 退出对话层，返回先前页面并恢复本地待机唤醒检测。
3. 回答中左键长按打断并沿用当前会话重新聆听；连接、聆听、思考、回答中右键短按取消并回来源页，右键长按取消并回首页。取消后旧回复／排队音频不得恢复回答。
4. 对话开始时暂停音乐／白噪声；结束后恢复仍然有效的原播放意图。
5. 用户取消、连接失败和超时都必须释放输入输出资源，提供可理解的结果，不能无限卡在聆听或思考状态。
6. 用户或 AI 在对话期间明确改变播放意图时，以新的操作为准。例如“停止音乐”之后不能自动恢复之前的音乐。
7. 采用用户指定的小星 LunarLink 平台：Board 绑定设备账号，gateway 提供 MQTT／加密 UDP 会话；复用设备身份，不再使用小智激活码。端点可配置，凭据由现有身份所有者管理；不自建首发云端 ASR／LLM／TTS。边界及当前验证范围见 [平台接入](07-lunarlink-platform.md)。

全局助手覆盖当前页面，不创建第二套导航主栈。跨模块命令通过业务接口执行，不通过模拟点击或操作页面控件完成。

## 5. 打断、提醒与重启

| ID | 场景 | 已确认行为 |
| --- | --- | --- |
| B-01 | 进入游戏 | 暂停音乐／白噪声，离开游戏后按有效播放意图恢复 |
| B-02 | 发起对话 | 暂停音乐／白噪声，单轮结束或取消后返回原页面，按有效意图恢复 |
| B-03 | 提醒／番茄钟到点 | 弹窗＋一次短提示音；未处理的提醒保留为待查看 |
| B-04 | 对话期间到点 | 立即显示提醒标记，等对话结束再弹窗和播放提示音 |
| B-05 | 关机期间错过提醒 | 开机取得可信时间后标为“已错过”，显示待查看提示，不补响 |
| B-06 | 番茄钟期间重启 | 保存轮次与计时状态，重启后暂停并等待用户确认继续 |
| B-07 | 重复提醒 | 按周规则继续计算下一次；查看或处理本次提醒不删除整个重复规则 |

“待查看”“已错过”“已处理”是记录状态，与未来的提醒计划分开。多条同时到达、游戏中的提醒弹窗、游戏内发起助手的暂停细节按技术方案推荐策略实现，并纳入 P0／P1 决策记录；不得改变上表已确认语义。

## 6. 首发排除项

不开放应用商店、动态 ELF 应用、Python／WASM 应用环境、面向用户的通用文件浏览器。已有相关源代码可以保留，构建只纳入真实依赖，不能为禁用入口随意删除底层被引用的代码。

不增加蜂窝菜单、动画壁纸、自定义“大肥鱼”唤醒模型、默认连续多轮对话、在线音乐平台、外部日历账号、多电脑管理、电脑远控或公网管理。

## 7. 完成的含义

首发完成需要六模块、设置和相关网页／电脑端形成可用流程，并通过联合验收。菜单可点击、静态演示、云端返回文本、编译通过都不能单独算作功能完成。

UI 骨架是独立的中间交付：允许显示明确的“尚未接入”状态，不能展示假天气、假电脑指标或假成功反馈。具体用例见 [验收清单](05-acceptance.md)。
