# 旧版基线修正

日期：2026-11-10。用户要求以此前已回退烧录并确认界面的版本抽离独立工程。之前独立项目误取 1.2.5 新桌面代码；其隔离构建成功只能证明构建闭包，不能证明符合用户所需交互。原记录 [standalone-validation.md](standalone-validation.md) 保留当时条件，本文件记录修正后的事实。

## 源码与架构

- 基线：`f1587d4fa682c33cbb69d0c65805c170ef1ac7e1`，版本 1.0.35，提交主题“智能音箱交互优化”。历史烧录记录包含用户确认“已显示旧版界面”。
- 保留历史工作区后续的双输出诊断和触摸扫描修改；GPIO 使用该版已版本化的当前接线，旧 README 中过期引脚表不作为真源。
- 恢复旧版 Pebble/音乐、本地菜单和网页；从相同基线取得 OS、Pet、BSP、音频辅助和驱动的实际依赖。没有拼装 1.2.x 标准桌面、GMF 或后来 Resource 契约。
- 移植旋钮输入修复：ISR 1 ms 去抖、有限音量增量合并、每轮有界命令处理。新增回归用 10,000 条音量输入验证不占满播放队列，普通命令继续前进。真机另外暴露 Flash 缓存暂停时 GPIO 读取和旋钮转换表仍位于 Flash：启用 GPIO 控制函数 IRAM，并将转换表放入 DRAM；路径审计同时检查链接后 ISR、调用函数、查表和状态的实际存储区。
- 显式 13 个本地组件；字体、分区、测试和资源暂存路径只引用本工程。删除依赖另一产品源码的旧 OS 测试夹具；原仓库 Git 历史、其他产品目录和设备凭据未导入。

## 设备与发布

误装 1.2.5 的应用 OTA 返回 HTTP 409 / `ota_recovery_required`，没有接收旧版镜像。改用 USB 在已选中的 `ota_1`（`0x620000`）写应用，ROM MAC、分区与 OTA 选择记录已交叉核对，保留分区表、NVS、字体和另一应用槽。首份旧版镜像捕获两次 Cache error，定位到 `gpio_get_level` 和旋钮转换表位于 Flash，已据此修复并重新构建。最终镜像通过 USB 写入并校验，串口 ELF 摘要前缀 `813abd58f` 与产物一致。最终镜像首轮观察至运行 139 秒：只有一次启动，没有 Cache error 或 panic；设备报告 1.0.35 / ESP-IDF 6.0.1，运行与启动槽均为 `ota_1`，已确认且无需待验证。SD 和音频 ready、曲库 5 首、字体加载成功，触摸控制器在 `0x38` 响应。

随后用同一镜像验证 OTA 传输，完整接收 3,513,216 bytes 后按原版规则返回 `ota_version_not_newer`，没有切换启动槽；因此本次最终安装方式为 USB，并未宣称完成同版本 OTA 激活。该传输期间记录两次 IDLE1/Wi-Fi 看门狗告警，没有重启，属于尚未解决的升级负载观察项。用户在最终镜像安装后，对“旧版界面、触摸、左右声道和连续旋转旋钮”的检查回复“是这个旧版，操作正常”。本次对应实体操作验收通过；不扩展为长期播放、升级负载或全部功能验收。设备证据只保存在忽略提交的本机目录。未提交、推送或发布。
