# Pet 交互模块

小智能力完整归属 Pet，源码按职责拆分：

- `conversation/`：对话状态、轮次、聆听与回复、打断、启停策略、事件发出。
- `voice/`：唤醒、语音检测、音频流与 Opus 编解码。
- `transport/`：小智激活、MQTT/UDP 连接与协议消息。
- `tools/`：MCP 编解码、回复队列、通用应用工具适配。
- `input.cpp`：将对话事件转换为 Pet 语义事件；文字转录不直接修改心情。

对话发出的状态与情绪直接进入 Pet，产品回调是可选观察者，不参与内部连线。
通用应用工具在对话初始化时安装，实际调用委托 `actions/capability_client`，由 OS 验证和分派。
模块共享既有会话执行上下文及同步约束，不因目录拆分增加工作任务。

MCP 分派器通过 `tools/assistant_mcp.h` 的 `McpContext` 接收回复队列、工具注册表、会话 ID
和错误出口，不再导入会话核心或访问 `g_runtime`。协议编码使用局部 JSON 文档；网络发送由
会话模块处理。工具执行前预留回复容量，释放会话锁后调用，重新加锁后校验队列代次和会话 ID。
其他音频、传输与会话协调仍共享现有执行上下文；此接口拆分没有改变它们的线程模型。

小智专有协议名称保留在传输实现和外部设备协议中。网络、音频物理资源、资源下载、OTA
与 DeviceLink 由 OS/对应提供者负责，交互模块不拥有这些系统能力。

仓库历史上使用过小智官方参考实现；源码的来源和许可证审计记录仍需在对外分发流程中维护。
